## coding

Q: Python dasturlash tilida ro‘yxat (list) elementlarini teskari tartibda chiqarish funksiyasini yozing.
A: Python-da ro‘yxatni teskari tartibga keltirish uchun quyidagi usuldan foydalanish mumkin:
```python
def reverse_list(lst):
    return lst[::-1]

# Misol:
print(reverse_list([1, 2, 3, 4]))  # [4, 3, 2, 1]
```

Q: Berilgan matnda "a" harfi necha marta qatnashganini hisoblaydigan Python funksiyasini yozing.
A: Buning uchun satr obyektining `.count()` metodidan foydalanish qulay:
```python
def count_letter_a(text):
    return text.lower().count('a')

# Misol:
print(count_letter_a("Assalomu alaykum"))  # 4
```

Q: SQL-da `Users` jadvalidan `age` ustuni 18 dan katta bo‘lgan barcha foydalanuvchilarning ismini (`name`) oladigan so‘rovni yozing.
A: Quyidagi SQL so‘rovi orqali bu ma’lumotni olish mumkin:
```sql
SELECT name FROM Users WHERE age > 18;
```

Q: Python dasturlash tilida berilgan sonning tub (prime) yoki murakkab ekanligini aniqlovchi funksiya tuzing.
A: Tub sonni aniqlash uchun quyidagi optimallashtirilgan algoritmdan foydalanish mumkin:
```python
def is_prime(n):
    if n <= 1:
        return False
    for i in range(2, int(n**0.5) + 1):
        if n % i == 0:
            return False
    return True
```

Q: JavaScript-da massiv ichidagi eng katta sonni topuvchi funksiya yozing.
A: JavaScript-da `Math.max` va spread operator yordamida eng katta sonni osongina topish mumkin:
```javascript
function findMax(arr) {
    return Math.max(...arr);
}
```

Q: JSON nima va u nima uchun ishlatiladi?
A: JSON (JavaScript Object Notation) — ma’lumotlarni saqlash va boshqa tizimlar bilan almashish uchun ishlatiladigan matnli formatdir. U asosan veb-server va mijoz (brauzer) o‘rtasida ma’lumot uzatishda keng qo‘llaniladi va inson hamda kompyuter o‘qishi uchun juda qulaydir.

Q: Python-da `try-except` bloki nima maqsadda ishlatiladi?
A: `try-except` bloki dastur bajarilish jarayonida yuzaga kelishi mumkin bo‘lgan xatoliklarni (exceptions) ushlash va dasturni to‘xtab qolishidan asrash (xatolikni chiroyli tarzda qayta ishlash) uchun ishlatiladi.

Q: HTML-da havola (link) yaratish uchun qaysi teg ishlatiladi?
A: HTML-da havola yaratish uchun `<a>` tegi va uning `href` atributidan foydalaniladi. Masalan: `<a href="https://example.com">Havola matni</a>`.

Q: Git-da yangi tarmoq (branch) yaratish va unga o‘tish buyrug‘ini yozing.
